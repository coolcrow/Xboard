# 接入节点方案：低成本·三网分别接入（定稿 v7）

> 需求一句话：**低成本 + 电信/移动/联通用户分别接入 + 一台落地**。
> 配套：[面板部署方案](./PANEL-DEPLOYMENT-PLAN.md)（RackNerd + Cloudflare 橙云）。
> 节点安装操作见 [QUICKSTART §三](./QUICKSTART.md)。

## 一、目标架构

```
电信用户     ──▶ Pro 入口（CN2 GIA）──────────┐
                                            ├──▶ 共享落地 RackNerd（IP 永不暴露）
移动/联通用户 ──▶ EB 入口（CMIN2 + 9929）──────┘

入口层目标价：$36.9 + $39.9 = $76.8/年（两台 DMIT WEE 限量款）
```

两个入口同时出现在用户订阅里，互为备份——一个被墙另一个照常服务。
接入机只跑 realm 转发 + agent，1C/1G 规格足够。

## 二、为什么分两步：WEE 是限量款

$36.9 的 Pro.WEE 和 $39.9 的 EB.WEE 都是 DMIT **年付限量款**，不是常备货
（2026-10 核验：官方在售 Pro 从 TINY $10.90/月起；EB 系列整体缺货；限量款
在 NodeSeek 有 ¥600-1000 二手溢价——稀缺性可见）。所以：**今天用常备款起步，
蹲到限量款再切换，机器和配置都不用动架构。**

⚠️ **下单防呆**：常备货里有个 T1.WEE 同价 $36.9——T1 是国际线路，**没有任何
中国优化**，买错等于白买。认准系列名是 **Pro** 或 **EB**。

## 四、第二步：蹲到限量款就切换（降本 + 分流）

| 蹲到什么 | 价格 | 动作 | 收益 |
|---|---|---|---|
| **EB.WEE** | $39.9/年 | 加为第二入口；节点命名"移动/联通优选" | 移动/联通用户走专属线路；双入口互备；总流量翻倍 |
| **Pro.WEE** | $36.9/年 | 替换 Pro.TINY（450GB/月） | 入口层降到 $76.8/年，全系统稳态 **≈ $122/年 ≈ ¥73/月** |

蹲货途径：① DMIT 官网等补货（上一轮 EB.WEE 补货在 2025-11）；
② NodeSeek 收二手，溢价 ¥600 以内可收（比 Pro.TINY 年付还便宜）。
**蹲不到不影响运行**——Pro.TINY 一直顶着，只是每年多花 $94。
