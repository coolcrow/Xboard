# 接入节点方案：搬瓦工 GIA-E（三网精品）

> 接入节点选型定稿（2026-10-13）。接入节点 = **用户直接连接的入口**，线路质量
> 决定全部用户体验——本方案的筛选把"三网晚高峰表现"放在第一位，价格第二。
> 配套阅读：[面板部署方案](./PANEL-DEPLOYMENT-PLAN.md)（RackNerd + CF 橙云）。

## 一、定位与架构角色

```
Phase 1（起步，本方案）：
  用户 ──▶ GIA-E（接入+落地一体，直连形态，无需 realm）
Phase 2（>30 用户）：
  用户 ──▶ GIA-E（纯接入）──realm──▶ 廉价落地机（RackNerd 等）
           （GIA 流量只承载"入口→落地"一段，落地池扩容成本 1/10）
```

> Phase 1 一台机器即可上线收费；Phase 2 拆分时 GIA-E 不用换机，改配置即可。

## 二、筛选标准（六维）

| 维度 | 权重 | 说明 |

| 运维简单度 | ⭐ | 控制台成熟度、机房切换、快照 |

## 四、结论：买什么、怎么买

```
商品     CN2 GIA-E SPECIAL 20G KVM PROMO V5（E-Commerce 系列）
计费     年付 $169.99（比季付省 2 个月）
机房     下单后切 DC6（洛杉矶，电信/移动优选）或 DC9（同线路 + AMD EPYC/NVMe）
支付     支付宝；无实名
备注     30 天可退（流量消耗 <10% 且 IP 正常）；近年无公开优惠码属正常
```

**备选触发条件**：下单时 GIA-E 缺货（少见）→ 蹲 DMIT LAX.Pro WEE（$36.9/年），
或先买 DMIT LAX.EB WEE 过渡（$39.9/年，移动/联通为主）。

**升级路径**：1TB 月流量用满（≈30 活跃轻量用户）→ 升 GIA-E 40G（$299.99/年）
或直接进 Phase 2 拆分（落地流量成本 1/10，优先推荐拆分）。

## 五、到货后部署（Phase 1 直连形态）

```bash
# 0. IP 质量预检（接入 IP 必须干净）
#    浏览器打开 ping.pe 或 ip.check.place 输入新 IP：
#    - 三网延迟/丢包正常，无"被墙"标记
# 1. 装节点 agent：面板「节点」页 → 复制 install 命令 → SSH 到 GIA-E 执行
#    （详见 QUICKSTART §三「添加节点」）
# 2. 面板建节点：协议 trojan/hysteria2，host=GIA-E IP，443 端口
# 3. DNS：接入域名 A 记录 → GIA-E IP（灰云 DNS only，不过 CF）
# 4. 订阅验证：客户端导入，晚高峰跑一次测速记录基线
```

## 六、验证清单

- [ ] ping.pe 三网测速正常、无阻断记录（**下单后 30 分钟内做，赶在退款窗口**）
- [ ] 晚高峰（20:30-23:00）mtr 三网各一次，丢包 <1%
- [ ] agent 上线、心跳正常、内核启动
- [ ] 订阅导入客户端，速度达到套餐标称带宽的 70%+
- [ ] DNS 记录灰云（直连，绝不过 CF——与面板方案同一硬规则）

## 七、边界与风险

| 风险 | 说明 | 处置 |
|---|---|---|
| 入口 IP 被墙 | 接入 IP 是全网唯一暴露面 | KiwiVM 后台切机房（免费即时换 IP）→ DNS 改记录 → 恢复 |
| 流量超限 | 1TB/月用尽 | 搬瓦工超量按 GB 计费（贵）；触发前升档或进 Phase 2 |
| 机房切换丢数据 | 切机房=重装盘 | 接入机保持无状态（配置在面板，agent 重装即恢复） |
| GIA 拥堵（极端） | 电信大促/晚高峰偶发 | DC6↔DC9 互切；长期看 Phase 2 拆分隔离 |
