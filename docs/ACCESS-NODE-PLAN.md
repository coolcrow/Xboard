## 一、目标架构

```
电信用户     ──▶ Pro 入口（CN2 GIA）──────────┐
                                            ├──▶ 共享落地 RackNerd（IP 永不暴露）
移动/联通用户 ──▶ EB 入口（CMIN2 + 9929）──────┘

入口层目标价：$36.9 + $39.9 = $76.8/年（两台 DMIT WEE 限量款）
```

两个入口同时出现在用户订阅里，互为备份——一个被墙另一个照常服务。
接入机只跑 realm 转发 + agent，1C/1G 规格足够。

## 二、为什么分两步：WEE 是限量款

（2026-10 核验：官方在售 Pro 从 TINY $10.90/月起；EB 系列整体缺货；限量款
在 NodeSeek 有 ¥600-1000 二手溢价——稀缺性可见）。所以：**今天用常备款起步，
蹲到限量款再切换，机器和配置都不用动架构。**

⚠️ **下单防呆**：常备货里有个 T1.WEE 同价 $36.9——T1 是国际线路，**没有任何
中国优化**，买错等于白买。认准系列名是 **Pro** 或 **EB**。

### 补充：入口域名化（借鉴机场打法，被墙恢复从"分钟级操作"变"一条 DNS"）

> 拆解商用机场（mihomo 订阅）的接入策略后采纳的一条：**面板节点的 host
> 填域名，永不填裸 IP**。

```
做法：  面板节点 host = gz1.你的域名（灰云 A 记录 → 入口 IP，TTL 60-300s）
被墙：  入口 IP 被封 → 改一条 A 记录指向新 IP → TTL 内全体客户端自动切
        —— 不用重推订阅、用户零感知、不用等换 IP 窗口
原理：  realm 是 L4 转发，TLS 在落地内核终结（证书/SNI 用落地域名）——
        入口域名只替换"连哪里"，不碰证书链，采纳成本为零
对照：  机场 22 个节点共用一个入口域名，被墙时它也是改 DNS 续命——
        这招是行业验证过的；但它单入口是 SPOF，我们的多入口互备更强
```

**不采纳的两条**：①单一共享入口（22 节点同生共死，那晚的"瞬断"就是
共享入口抖，url-test 切节点无效——我们多入口架构天生免疫）；②DNS
round-robin 多入口（软 HA 不可靠，订阅多节点 + 客户端 url-test 更确定）。
