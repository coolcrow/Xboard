## 一、定位与架构角色

```
路线 A（单机直连起步）：
  用户 ──▶ GIA-E（接入+落地一体，无需 realm）
路线 B（多入口，天生转发形态）：
  电信用户 ──▶ Pro 入口 ──┐
  移动/联通 ──▶ EB 入口 ──┴─realm─▶ 共享落地（RackNerd，IP 永不暴露）
```

> 路线 A 之后可平滑转 B：GIA-E 改纯接入 + 加落地即可，机器不换。
> 路线 B 的多入口是本系统的一等公民：喂入机列表自动推导、落地防火墙
> 白名单自动收敛（增删入口零手工）、订阅多入口并存互为备份。

## 四、结论：两条路线，按"要几台"选

### 路线 A：单旗舰（一台搞定，省心）

```
商品     CN2 GIA-E SPECIAL 20G KVM PROMO V5（E-Commerce 系列）
计费     年付 $169.99（比季付省 2 个月）
机房     下单后切 DC6（电信/移动优选）或 DC9（同线路 + AMD EPYC/NVMe）
支付     支付宝；无实名
备注     30 天可退（流量 <10% 且 IP 正常）
```

### 路线 B：多入口分流（多台接入 + 预算敏感，⭐ 推荐）

| 角色 | 采购 | 线路 | 流量 | 价格 |
|---|---|---|---|---|
| 入口 1（电信） | DMIT LAX.Pro WEE 1C/1G | 三网回程 CN2 GIA | 450GB/月 | $36.9/年 |
| 入口 2（移动/联通） | DMIT LAX.EB WEE 1C/1G | CMIN2 + 9929（电信回程 9929） | 1TB/月 | $39.9/年 |
| 共享落地 | RackNerd 1C/1G | 普通（IP 藏入口后，不怕脏） | 2TB/月 | ~$14/年 |

```
多入口合计 ≈ $91/年——比单台 GIA-E 便宜 47%，且：
· 容灾：任一入口被墙，另一个照常服务（订阅双入口并存）
· 分流：电信用户连 Pro 入口（GIA），移动/联通连 EB 入口（各自精品线路）
· 线性扩容：流量不够再 +$40/台加同款入口，不碰 $299 垂直升级
· 接入机在转发形态只跑 realm + agent，1C/1G 绰绰有余
· 新入口上线 = 面板建机器 + 装 agent 共 15 分钟（防火墙白名单自动收敛）
合计流量 1.45TB/月 ≈ 45 个轻量用户（vs GIA-E 1TB ≈ 30）
```

代价：① 电信入口仅 450GB（≈15 个电信重度用户，超了再加一台 Pro WEE）
② DMIT 库存波动（2026-05 曾全线缺货）——下单时无货就先只买 EB 入口 +
GIA-E 过渡，蹲到再换。

**路线选择（已定）**：✅ **B**（要多台、预算敏感、接受蹲货）。
全系统成本（含面板方案）：**B ≈ $113/年（4 台机器）**。
A 仅作 DMIT 缺货时的过渡：先 GIA-E 单机直连上线，蹲到 WEE 货再转 B
（转换 = GIA-E 改纯接入 + 加落地，机器不换）。

### 升级路径（两路线通用）

入口流量将满 → 水平加一台 WEE 入口（+$37-40/年，15 分钟上线）；
落地流量将满 → 加 RackNerd 落地（+$14/年）。**永不垂直升级。**

## 七、边界与风险

| 风险 | 说明 | 处置 |

| 入口 IP 被墙 | 接入 IP 是全网唯一暴露面 | KiwiVM 后台切机房（免费即时换 IP）→ DNS 改记录 → 恢复 |
