# 商业授权技术附件（草案）

> 供合同起草参考的参数建议。法律措辞需专业审校；本文只定义可执行的技术授权边界。

## 授权模型建议

按 **部署实例（deployment）** 计费，一个实例 = 一套面板 + 绑定的节点机群。

| 参数 | 建议档位 | 技术对应 |
|---|---|---|
| 域名数 | 1 套用户域 + 1 套管理域（默认）/ 加购 | 面板的双域名配置 |
| 节点数 | 不限（agent 开源，无技术门槛） | agent 为 MPL/GPL，无法也不应限制 |
| 授权期 | 12 个月，含更新 | 镜像访问令牌有效期对齐 |
| 更新 | 授权期内镜像 + 面板/主题更新 | ghcr 令牌续期 |
| 支持 | 工单（远程），响应按 SLA 分档 | 面板工单系统或独立渠道 |

## 交付物清单（单客户）

1. ghcr.io 镜像访问令牌（read:packages，仅限 `coolcrow/xboard` 包）
2. `INSTALL-CUSTOMER.md` 安装手册
3. 管理后台初始配置清单（域名/品牌/支付/实测数据）
4. agent 安装命令（公开仓库，无需凭证）

## 技术控制点现状与边界

| 控制点 | 现状 | 说明 |
|---|---|---|
| 主题源码 | 私有仓库 | 授权客户不获得源码，仅获得镜像 |
| 运行镜像 | ghcr 私有包（待转） | 合同终止即吊销令牌，不再可拉新版本；已拉取版本无法远程禁用（见下） |
| agent | 开源 | 无控制，也不需要 |
| 面板许可校验 | 无 | 无 License Key/激活机制——合同违约靠商务追责 |

**已知边界（签约前应知晓）**：
- 无技术防拷贝：客户可复制已部署实例到其他域名（域名数约束是商务条款，非技术强制）。若需技术强制，属 Phase 3（License Server：面板启动校验签发的域名绑定 Key）
- 镜像层可被提取：授权客户技术上可从镜像中取出打包后的前端资产。源码不可得，但混淆前端的再利用无法完全阻止
- 中止服务 = 停止更新 + 吊销拉取，不能远程关停运行中的实例

## 定价维度参考（非本附件范围，仅列影响因子）

部署实例数 × 授权期 × 支持档位；节点数不构成价格维度。
